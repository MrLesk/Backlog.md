Backlog.md keeps a project's tasks, plans, acceptance criteria and outcomes as Markdown files in the repository. One `backlog` executable offers a CLI, a terminal board, a local web UI and an optional MCP server, and every surface edits the same files through one shared core. This map shows who uses it, its two runtime boundaries (the executable and the browser app), and the files and Git history it works on.
