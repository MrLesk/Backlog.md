Turns any folder or Git repository into a project board backed by plain Markdown files. Developers and AI coding agents capture intent as tasks, review scope and plans before code is written, track progress, and keep finished work as a readable record. The CLI is canonical; the terminal UI and the browser are views over the same model, and MCP is an optional adapter. No account, hosted backend or telemetry is involved.
